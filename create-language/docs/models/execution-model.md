## 寄存器机执行

### 指令格式
- 固定 32 位指令宽度
- 操作码在低 8 位：`instruction & 0xFF`
- 5 种编码格式：RRR、RRI、RI、I、RRK
- 通过 `wide` 前缀指令扩展为 64 位

### 调用帧
```rust
struct Frame {
    registers: Vec<Value>,    // 寄存器数组
    pc: usize,                // 程序计数器
    closure: GcRef<Closure>,  // 当前闭包
    ip: usize,                // 指令指针（在字节码数组中的偏移）
}
```

### 函数调用
1. 调用者将参数放入寄存器 R0..R(N-1)
2. `CALL func N` 指令创建新 Frame，参数从调用者寄存器复制
3. 被调用者执行，`RETURN Rk` 将结果放入寄存器
4. Frame 弹出，调用者从目标寄存器读取返回值

## 类型系统

### 编译期
- Hindley-Milner 类型推断
- 标注类型 → 检查；未标注 → 推断
- 类型擦除前生成类型注解到字节码常量池

### 运行时
- 第一阶段：`enum Value` 表示所有值，16 字节
- 第二阶段（性能优化）：NaN-boxing，8 字节
- 类型特化：编译期已知类型时，生成 `ADD_INT`/`ADD_FLOAT` 等特化指令

## 闭包实现

```rust
struct Closure {
    function: GcRef<Function>,      // 函数字节码
    upvalues: Vec<GcRef<Upvalue>>,  // 捕获的变量
}

struct Upvalue {
    location: Location,  // 栈上或堆上
    closed: Value,       // 逃逸后闭包的值
}

enum Location {
    Stack(usize),        // 还在栈上（Frame 寄存器索引）
    Heap,                // 已逃逸到堆
}
```

## 字节码模块系统

每个 `.cl` 文件编译为一个 `.clc` 文件，包含：
- 魔数 + 版本号
- 常量池（字符串、数字、函数原型、类型签名）
- 函数原型表（每个函数的指令数组、寄存器数、参数数）
- 导出表（public 的函数/类型/常量）
- 导入表（依赖的其他 `.clc` 文件）

模块加载时：
1. 解析 `.clc` 文件
2. 递归加载依赖
3. 链接符号（解析导入表 → 匹配导出表）
4. 初始化全局变量
